# Server and network

Gate: none for the file. SRV-01 to SRV-03, SRV-09 and SRV-10 are gated per row on self-hosted servers (N/A on managed hosting, with the reason).

| ID | Tier | Stage | Check | How to verify | Evidence to record | Attest |
|---|---|---|---|---|---|---|
| SRV-01 | T0 | - | (gate: self-hosted servers, database) The database is not reachable from the internet. | Probe the DB port from outside the network; list listening sockets and bind addresses; read the cloud firewall rules and the DB host-based access rules for any world-open entry, including the address keywords `all` and `samenet` on non-local rules. Read container compose `ports:` bindings: a published DB port binds every interface and bypasses host firewall rules such as ufw; it should bind `127.0.0.1` or be unpublished. e.g. `ss -tlnp \| grep 5432` shows localhost or private network only; `pg_hba.conf` has no `0.0.0.0/0`, `::/0`, `all` or `samenet` on remote rules; the cloud firewall denies 5432. Docker clause: a container database with no published port, reachable only on a docker network, PASSES even with `host all all all` in `pg_hba.conf`, because the network is the boundary; a published port does not. | Command output, firewall rule list, access-rule file lines, compose `ports:` lines |  |
| SRV-02 | T0 | - | (gate: self-hosted servers) The origin accepts web traffic only from the CDN/WAF (IP allowlist or tunnel), and CDN-to-origin TLS is fully verified. | Check the origin firewall allows 80/443 only from the CDN ranges or a tunnel; request the origin IP directly and expect a refusal; read the CDN TLS mode. e.g. Cloudflare SSL mode is Full (strict), not Flexible. | Firewall rules, direct-request result, TLS mode setting |  |
| SRV-03 | T0 | - | (gate: self-hosted servers) SSH is key-only, root password login is disabled, unattended security upgrades are on. | Read effective sshd config and the auto-update config on each box. e.g. `sshd -T \| grep -Ei 'passwordauthentication\|permitrootlogin'`; `systemctl status unattended-upgrades`. | Config values per box |  |
| SRV-04 | T0 | - | Encryption in transit everywhere, including app-to-database traffic between hosts. | Check DB connection strings for TLS mode; confirm internal hops and webhooks use TLS; confirm HTTP redirects to HTTPS. e.g. Postgres `sslmode=verify-full` in the URL, `SHOW ssl;`, `curl -I http://host`. | Connection string flags, config value, curl output |  |
| SRV-06 | T0 | - | Domains are on auto-renew with a valid payment method; certificate expiry is tracked with alerts before expiry, not on the day. | Check registrar auto-renew and card expiry; list cert expiry dates; find the expiry alert and its lead time. e.g. `echo \| openssl s_client -connect host:443 2>/dev/null \| openssl x509 -noout -enddate`. | Registrar setting, cert dates, alert rule |  |
| SRV-07 | T1 | 100 | A CDN caches static assets so the app loads fast far from the origin. | Request a static asset and read cache headers and hit status from a remote location. e.g. `curl -sI https://host/_next/static/x.js \| grep -i 'cache-control\|cf-cache-status'`. | Response headers |  |
| SRV-08 | T2 | - | A second region or standby exists only if a contract promises uptime one box cannot deliver; autoscaling is needed only if load testing shows it. | Read the contract uptime terms and the measured capacity; compare against the topology. N/A on fixed servers without such a promise. | Contract clause, topology notes, load test result |  |
| SRV-09 | T0 | - | (gate: self-hosted servers) Disk-fill protection: log rotation (journald and container log driver size caps), a scheduled image and build-cache prune, and a disk alert at about 80%. | Read journald limits and the container logging options; find the prune job and its last run; find the disk alert and its threshold. e.g. `journalctl --disk-usage`; compose `logging:` with `max-size` and `max-file`; `docker system df`; a cron job or timer running `docker system prune`. | Config values, prune job, alert rule |  |
| SRV-10 | T0 | - | (gate: self-hosted servers) Server timezone is UTC, the clock is NTP-synced, and containers have memory limits and a restart policy. | Read time settings and container config on each box. e.g. `timedatectl`; compose `mem_limit` or `deploy.resources.limits` and `restart:`. | Command output, compose lines |  |
